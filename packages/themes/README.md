# @trackpress/themes

Declarative visual themes for TrackPress renderers.

```ts
import { getTheme } from "@trackpress/themes";

const theme = getTheme("neon-night-drive");
```

Built-in themes are validated against the contracts from `@trackpress/core` and do not execute
arbitrary code. See the [TrackPress repository](https://github.com/TrackPress/TrackPress) for full
documentation.
